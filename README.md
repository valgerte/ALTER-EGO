# ALTER EGO
## Сублимация тревоги

ALTER EGO — интерактивный веб-арт-проект, в котором внутреннее напряжение обретает форму и звук.

День складывается из актов — отдельных мгновений с разной интенсивностью переживания. Они задают состояние полупрозрачной стеклянной скульптуры и характер её звучания. Прикосновения, сжатия и движения по поверхности превращаются в звуковые жесты.

Скульптура становится пространством взаимодействия с собственным опытом. Пульс, стекло и дыхание складываются в звуковой портрет дня. Его можно записать, а состояние дня — сохранить и открыть снова.

[Открыть проект](https://valgerte.github.io/ALTER-EGO/)

## Взаимодействие

- Создавайте от трёх до шести актов и задавайте напряжение каждого.
- Прикасайтесь к форме, сжимайте и растягивайте её.
- Соединяйте звуковые слои: пульс, стекло и дыхание.
- Оставляйте след — записывайте жесты в повторяющуюся петлю.
- Записывайте звучание и скачивайте аудио.
- Сохраняйте отпечаток дня в JSON, чтобы вернуться к нему позже.

Проект рассчитан на компьютер и горизонтальный экран. Для живой формы нужен WebGL 2, для звучания — Web Audio. Звук запускается после нажатия соответствующей кнопки.

## Технологии и разработка

Визуальная часть использует Three.js, звуковая — Tone.js. Интерфейс реализован на HTML, CSS и JavaScript.

**В работе над проектом использовались Codex и Claude Code.**

Разработка продолжается в этом репозитории. GitHub Pages автоматически публикует изменения из ветки `main`.

## Локальный запуск

В папке проекта запустите:

```bash
python3 -m http.server 5173
```

Откройте [localhost:5173](http://localhost:5173) в браузере.

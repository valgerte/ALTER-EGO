# ALTER EGO — Сублимация тревоги

Восстановленная опубликованная версия https://alter-ego-glass-day.idealmoss3.chatgpt.site/ на 31 октября 2026.

## Запуск

Из папки проекта: `python3 -m http.server 5173`, затем http://localhost:5173.
Нужен браузер с WebGL и Web Audio. Звук включается действием пользователя.

## Файлы

- `index.html` — страница приложения.
- `assets/index-DS9l8ha4.js` — код приложения из опубликованной сборки.
- `assets/index-CcOPzZFo.css` — стили.
- `assets/tone-CKHlch0c.js`, `assets/three-Gk1LYPx1.js` — опубликованные библиотеки, содержащие их лицензионные комментарии.
- `assets/alter-ego-logo.png` — логотип опубликованной версии.
- `legacy/` — HTML и CSS прежней страницы репозитория, сохранены перед переносом. Изображение остаётся в корне.

Скачаны HTML и все его JS/CSS зависимости, а также изображение, указанное в коде приложения. Файлы сборки сохранены без изменений.
